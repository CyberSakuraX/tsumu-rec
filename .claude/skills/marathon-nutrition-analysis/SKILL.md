# マラソン栄養×コンディション分析

対象読者はClaude自身。山崎さんから分析を依頼されたときにこの手順に従う。
書き込み経路(iPhone→Notion API)にはこのSkillは関与しない。読み取り専用の分析フローである。

## 1. 対象期間を決める
- 依頼文に期間の指定があればそれに従う(例: 「直近1ヶ月」「◯◯レース前3週間」)
- 指定がなければ直近4〜8週間をデフォルトとする
- 「ピーキング期」と言われたら、対象レースの日付を山崎さんに確認するか、
  Notion上の `ピーキングフラグ = true` の連続期間から推定する

## 2. Notion MCP でログを取得
- 対象DB: 「食事・コンディション ログ」
  - database_id: `0e691aca69b34d49866d5c3494222d5c`
  - data source: `collection://5ac49255-f3b4-4194-87a7-961876072a00`
- 対象期間で `日付` フィルタをかけて全行を取得する
- 各行から、朝食/昼食/夕食/間食、目覚め、睡眠時間、体感、気分指数、不快指数、開放、
  好調・不調メモ、ピーキングフラグ、および該当する場合はピーキング期限定項目
  (炭水化物比率の体感/塩分電解質メモ/胃腸の負担感)を読み取る

## 3. Strava MCP でトレーニングデータを取得
- 同じ期間の活動一覧を取得する
- 特に長距離走・レース・高強度練習については、パフォーマンス指標
  (ペース、相対的な負荷、心拍、後半の失速有無など)を個別に深掘りする

## 4. 突き合わせの観点
- 前夜/当日朝のコンディション(睡眠時間・目覚め・体感・気分指数・不快指数)と、
  その日または翌日のトレーニング強度・パフォーマンスの関係
- 「開放」の記録と、翌日以降のパフォーマンスへの影響傾向
- 食事内容(自由記述)の傾向と、調子の良かった日・悪かった日の対応関係
- ピーキング期に限り、炭水化物比率の体感・塩分電解質メモ・胃腸の負担感と、
  レース当日または当該高強度練習のパフォーマンスとの関係を重点的に見る

## 5. 出力形式
- 期間中の傾向を短くまとめたサマリー
- 相関が見られた具体的な事例(日付を添えて)
- 次のレース/ピーキング期に向けた、具体的で実行可能な提案
- データが薄く相関を断定できない場合は、断定せずその旨を明示する
