# iPhoneショートカット 作成手順(タップ順)

`docs/iphone-shortcuts.md` が「何を作るか」の設計、こちらが「どう作るか」の実装手順。

## 全体の作り

upsert処理(今日の行を検索 → 無ければ作成／有れば更新)を4つのショートカット全部に組むと、
同じものを4回作ることになる。そこで**その部分だけヘルパーに切り出す**。

```
ご飯記録 ┐
朝コンディション ├─→ [Notion書き込み] ── Notion API
夜コンディション │      (ヘルパー)
ピーキング切替 ─┘ ※これだけはヘルパーを使わない(ファイル書き換えのみ)
```

各ショートカットは「Notionに入れたいプロパティのJSON断片」を作ってヘルパーに渡すだけ。
**作る順番は ヘルパー → ご飯記録 → 朝 → 夜 → ピーキング切替**。ヘルパーを最初にテストで通しておくと後が楽。

所要時間の目安は全部で30〜40分。ヘルパーが一番重く、残りは10分弱ずつ。

---

## 事前準備

`docs/setup-status.md` の手順1・2を先に済ませておくこと。

- Notion Integration の Token を取得し、「🏃 マラソン管理」ページにコネクト済み
- iCloud Drive の `Shortcuts` フォルダに `notion_config.json` と `peaking_flag.txt` を配置済み

`peaking_flag.txt` は**改行なしで `false` の5文字だけ**にしておく。

---

## ショートカット0:「Notion書き込み」(ヘルパー)

ショートカットApp → 右上「+」→ 右上の設定アイコン(ⓘ/スイッチ) →
名前を `Notion書き込み` にし、**「共有シートに表示」はOFF**のままでよい。

以下、上から順にアクションを追加していく。アクションは下部の検索欄に名前を入れて探す。

### A. 設定ファイルを読む

1. **「ファイルを取得」**
   - サービス: `iCloud Drive`
   - 「ファイルピッカーを表示」を **OFF**
   - パス: `Shortcuts/notion_config.json`
2. **「入力からディクショナリを取得」**(入力は直前の「ファイル」のまま)
3. **「ディクショナリの値を取得」** — キー: `token`
4. **「変数を設定」** — 変数名: `token`、値: 直前の「ディクショナリの値」
5. **「ディクショナリの値を取得」** — キー: `database_id`、**入力を「ディクショナリ」(手順2の結果)に戻す**
   - ここが要注意。デフォルトだと直前の結果を拾ってしまうので、青い変数部分をタップして
     手順2の「ディクショナリ」を選び直す
6. **「変数を設定」** — 変数名: `db`、値: 直前の「ディクショナリの値」

### B. 今日の日付を作る

7. **「日付」**(現在の日付)
8. **「日付をフォーマット」**
   - 日付フォーマット: `カスタム`
   - フォーマット文字列: `yyyy-MM-dd`
9. **「変数を設定」** — 変数名: `today`

### C. ピーキングフラグを読む

10. **「ファイルを取得」** — iCloud Drive / ピッカーOFF / パス `Shortcuts/peaking_flag.txt`
11. **「もし」** — 入力を手順10のファイルにして、条件: `テキストが次を含む` → `true`
    - 「もし」の中: **「変数を設定」** 変数名 `flag`、値は **「テキスト」アクション**で `true`
    - 「その他の場合」の中: **「変数を設定」** 変数名 `flag`、値は「テキスト」アクションで `false`

> ヒント: 「テキスト」アクションを先に作ってから「もし」の中にドラッグすると入れやすい。

### D. 今日の行を検索する

12. **「テキスト」** — 中身を丸ごと以下にする(`today` の部分だけ変数を挿入)
    ```
    {"filter":{"property":"日付","date":{"equals":"today"}},"page_size":1}
    ```
    - `today` は手で打つのではなく、変数 `today` を挿入する(青いピル表示になればOK)
13. **「変数を設定」** — 変数名: `qbody`
14. **「URLの内容を取得」**
    - URL: `https://api.notion.com/v1/databases/db/query`
      (`db` の部分に変数 `db` を挿入。前後に余計なスペースを入れない)
    - 「詳細を表示」を開く
    - 方法: `POST`
    - ヘッダ: 「+」で3つ追加
      | キー | 値 |
      |---|---|
      | `Authorization` | `Bearer ` + 変数 `token`(Bearerの後ろに半角スペース1つ) |
      | `Notion-Version` | `2022-06-28` |
      | `Content-Type` | `application/json` |
    - 本文を要求: **`ファイル`** を選び、ファイルとして変数 `qbody` を指定
15. **「ディクショナリの値を取得」** — キー: `results`
16. **「変数を設定」** — 変数名: `results`

### E. 分岐して作成 or 更新

17. **「数を数える」** — 項目 / 入力は変数 `results`
18. **「もし」** — 条件: `数` `が次と等しい` `0`

**「もし」の中(= 今日の行がまだ無い → 新規作成)**

19. **「テキスト」** — 以下を丸ごと(`db` `today` `today` `ショートカットの入力` `flag` は変数を挿入)
    ```
    {"parent":{"database_id":"db"},"properties":{"名前":{"title":[{"text":{"content":"today"}}]},"日付":{"date":{"start":"today"}},"ピーキングフラグ":{"checkbox":flag},ショートカットの入力}}
    ```
    - `flag` にはクォートを付けない(true/false はJSONの真偽値)
    - `ショートカットの入力` は変数リストの「ショートカットの入力」を挿入する
20. **「URLの内容を取得」**
    - URL: `https://api.notion.com/v1/pages`
    - 方法: `POST`、ヘッダは手順14と同じ3つ、本文を要求: `ファイル` → 手順19のテキスト

**「その他の場合」の中(= 既に行がある → 更新)**

21. **「リストから項目を取得」** — 入力: 変数 `results` / 取得: `最初の項目`
22. **「ディクショナリの値を取得」** — キー: `id`
23. **「変数を設定」** — 変数名: `pageid`
24. **「テキスト」**
    ```
    {"properties":{"ピーキングフラグ":{"checkbox":flag},ショートカットの入力}}
    ```
25. **「URLの内容を取得」**
    - URL: `https://api.notion.com/v1/pages/pageid`(`pageid` は変数を挿入)
    - 方法: **`PATCH`**、ヘッダは同じ3つ、本文を要求: `ファイル` → 手順24のテキスト

### F. テストする

「もし」の外(一番下)に一時的に **「クイックルック」** を置いて、ヘルパー単体で実行してみる。
ただしヘルパーは単体だと「ショートカットの入力」が空になり、JSONに `,}` が残って **400** になる。
なので、テスト中だけ手順19/24の `ショートカットの入力` の部分を次のテキストに置き換えて実行する。

```
"好調・不調メモ":{"rich_text":[{"text":{"content":"テスト"}}]}
```

Notionの「食事・コンディション ログ」に当日の行ができ、**2回目の実行で行が増えず同じ行が更新される**
ことを確認できたら、置き換えた部分を「ショートカットの入力」に戻し、クイックルックを削除する。

エラーが出たときは `docs/notion-api-payloads.md` 末尾の「注意点」を参照。
`401` はToken間違いかコネクト忘れ、`400` はJSONの組み立てミス、`404` は database_id 違い。

## ショートカット1:「ご飯記録」

新規ショートカット、名前 `ご飯記録`。

1. **「メニューから選択」** — プロンプト: `何を記録する?`
   選択肢: `朝食` / `昼食` / `夕食` / `間食`
   - 4つの分岐それぞれの中に、**「変数を設定」** 変数名 `種別` を置き、
     値は「テキスト」アクションでそれぞれ `朝食` `昼食` `夕食` `間食` とする
2. メニューの外に **「テキストを書き取る」**(Dictate Text)
   - 言語: 日本語 / 停止のタイミング: `一時停止のあと`
3. **「テキストを置き換える」**(安全のため)
   - 検索テキスト: `"` / 置換後: `'` / 正規表現: OFF / 入力: 手順2の書き取ったテキスト
4. **「変数を設定」** — 変数名 `内容`
5. **「テキスト」** — 以下(`種別` `内容` は変数を挿入)
   ```
   "種別":{"rich_text":[{"text":{"content":"内容"}}]}
   ```
6. **「ショートカットを実行」** — ショートカット: `Notion書き込み` / 入力: 手順5のテキスト
   - 「実行中に表示」は **OFF** にする(体感速度優先)

起動方法は、ショートカットの設定から「ホーム画面に追加」、または
設定App →「アクセシビリティ」→「タッチ」→「背面タップ」に割り当てる。
Siriには「ご飯記録」と言えばそのまま起動する。

## ショートカット2:「朝コンディション」

新規ショートカット、名前 `朝コンディション`。

1. **「メニューから選択」** — プロンプト: `目覚めは?` / 選択肢: `1` `2` `3` `4`
   - 各分岐で **「変数を設定」** 変数名 `目覚め`(値は「テキスト」で `1`〜`4`)
2. **「メニューから選択」** — プロンプト: `睡眠時間は?`
   選択肢: `5h未満` `5-6h` `6-7h` `7-8h` `8h以上`
   - 各分岐で **「変数を設定」** 変数名 `睡眠`(値は選択肢と**完全に同じ文字列**)
3. **「テキスト」**
   ```
   "目覚め":{"number":目覚め},"睡眠時間":{"select":{"name":"睡眠"}}
   ```
   - `目覚め` にはクォートを付けない(数値)
4. **「ショートカットを実行」** — `Notion書き込み` に手順3を渡す

ピーキングフラグはヘルパー側で自動的に入るので、ここでは扱わない。

---

## ショートカット3:「夜コンディション」

新規ショートカット、名前 `夜コンディション`。ここだけ少し長い。

1. **「ファイルを取得」** — `Shortcuts/peaking_flag.txt`(ピッカーOFF)
2. **「変数を設定」** — 変数名 `flagtext`
3. **「メニューから選択」** `体感は?` → `軽` `並` `重` → 各分岐で変数 `体感` を設定
4. **「メニューから選択」** `気分指数は?` → `1`〜`5` → 変数 `気分`
5. **「メニューから選択」** `不快指数は?` → `1`〜`5` → 変数 `不快`
6. **「メニューから選択」** `開放は?` → `自慰` `性行為` `なし` → 変数 `開放`
7. **「メニューから選択」** `メモを残す?` → `はい` / `いいえ`
   - `はい` の中: **「入力を要求」**(テキスト) → **「テキストを置き換える」**(`"` → `'`) →
     **「テキスト」** で `,"好調・不調メモ":{"rich_text":[{"text":{"content":入力}}]}` を作り、
     **「変数を設定」** 変数名 `メモ部`
     ※先頭のカンマを忘れないこと
   - `いいえ` の中: **「テキスト」** を**空のまま**にして **「変数を設定」** 変数名 `メモ部`
8. **「もし」** — 入力: 変数 `flagtext` / 条件: `テキストが次を含む` `true`
   - **もしの中(ピーキング期)**
     a. **「メニューから選択」** `炭水化物比率の体感は?` → `少なめ` `適量` `多め` → 変数 `炭水`
     b. **「入力を要求」**(テキスト、プロンプト `塩分・電解質メモ`)→ 変数 `塩分`
     c. **「メニューから選択」** `胃腸の負担感は?` → `なし` `軽度` `中度` `重度` → 変数 `胃腸`
     d. **「テキスト」** で以下を作り、**「変数を設定」** 変数名 `ピーキング部`
        ```
        ,"炭水化物比率の体感":{"select":{"name":"炭水"}},"塩分電解質メモ":{"rich_text":[{"text":{"content":"塩分"}}]},"胃腸の負担感":{"select":{"name":"胃腸"}}
        ```
   - **その他の場合**: **「テキスト」** を空にして **「変数を設定」** 変数名 `ピーキング部`
9. **「テキスト」** — 以下(改行を入れずに1行で)
   ```
   "体感":{"select":{"name":"体感"}},"気分指数":{"number":気分},"不快指数":{"number":不快},"開放":{"select":{"name":"開放"}}メモ部ピーキング部
   ```
   - `メモ部` と `ピーキング部` は末尾に続けて挿入する。中身が空なら何も足されない
10. **「ショートカットを実行」** — `Notion書き込み` に手順9を渡す

## ショートカット4:「ピーキング切替」

新規ショートカット、名前 `ピーキング切替`。Notion APIは使わない。

1. **「ファイルを取得」** — `Shortcuts/peaking_flag.txt`(ピッカーOFF)
2. **「結果を表示」** — 現在値を確認するため(入力は手順1のファイル)
3. **「メニューから選択」** — プロンプト: `ピーキング期に切り替える?` / 選択肢: `ON` `OFF`
   - `ON` の中: **「テキスト」** に `true` → **「ファイルを保存」**
   - `OFF` の中: **「テキスト」** に `false` → **「ファイルを保存」**
4. **「ファイルを保存」** の設定(ON/OFF両方とも同じ)
   - サービス: `iCloud Drive`
   - 「保存先を確認」を **OFF**
   - 保存先パス: `Shortcuts/peaking_flag.txt`
   - **「上書き保存」を ON**(これをOFFにすると `peaking_flag 2.txt` が増えていく)

レース前2〜3週間の開始日と終了日に1回ずつ開くだけ。ホーム画面に置いておく。

## つまずきやすいポイント

- **「ディクショナリの値を取得」の入力が直前の結果に勝手に繋がる** — ヘルパー手順5で一番起きる。
  青い変数ピルをタップして正しい変数を選び直す。
- **「テキスト」アクションで変数を手打ちしてしまう** — `today` と文字で打っても展開されない。
  必ず変数を挿入して青いピルにする。
- **URLに余計なスペースや改行が入る** — `.../databases/[db]/query` の前後に注意。
- **selectの選択肢名の表記ゆれ** — `5-6h` を `5〜6h` などにするとNotion側に新しい選択肢が増える。
  メニューの選択肢名とJSONの `name` は完全一致させる。
- **「実行前に確認」** — オートメーション側ではONにする(通知として出すため)が、
  「ショートカットを実行」アクションの「実行中に表示」はOFFにする。別物なので混同しないこと。
- **`,}` や `{,` が残って400** — 「メモを残す?」で「いいえ」を選んだときなどに起きる。
  カンマは必ず**追加する側の先頭**に付ける(`,"好調・不調メモ":...`)ルールで統一している。
