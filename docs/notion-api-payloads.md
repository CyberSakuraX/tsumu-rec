# Notion API リクエストボディ集(ショートカット用コピペ元)

`database_id` = `0e691aca69b34d49866d5c3494222d5c`

全リクエスト共通のヘッダー:
```
Authorization: Bearer <token>
Notion-Version: 2022-06-28
Content-Type: application/json
```

`<TODAY>` は「日付をフォーマット」アクションで `yyyy-MM-dd` にした文字列(例: `2026-07-27`)。

---

## 共通ステップ1: 今日の行を探す

```
POST https://api.notion.com/v1/databases/0e691aca69b34d49866d5c3494222d5c/query
```
```json
{
  "filter": { "property": "日付", "date": { "equals": "<TODAY>" } },
  "page_size": 1
}
```

レスポンスの `results` が空なら**新規作成**、1件以上なら `results[0].id` を `<PAGE_ID>` として**更新**に進む。

## 共通ステップ2a: 新規作成

```
POST https://api.notion.com/v1/pages
```
```json
{
  "parent": { "database_id": "0e691aca69b34d49866d5c3494222d5c" },
  "properties": {
    "名前": { "title": [{ "text": { "content": "<TODAY>" } }] },
    "日付": { "date": { "start": "<TODAY>" } }
    // ↓ ここに各ショートカットの properties を差し込む
  }
}
```

## 共通ステップ2b: 既存行の更新

```
PATCH https://api.notion.com/v1/pages/<PAGE_ID>
```
```json
{
  "properties": {
    // ↓ 各ショートカットの properties だけを入れる。他の項目は変更されない
  }
}
```

## ショートカット1: ご飯記録

差し込む properties(`<種別>` は 朝食/昼食/夕食/間食 のいずれか、`<内容>` は音声入力テキスト):
```json
{
  "<種別>": { "rich_text": [{ "text": { "content": "<内容>" } }] },
  "ピーキングフラグ": { "checkbox": <ピーキング中> }
}
```

> `<種別>` はプロパティ名そのものが変数になる。ショートカットでは「テキスト」アクションで
> JSON文字列を組み立てて「URLの内容を取得」のリクエストボディに `ファイル` として渡すのが確実。
> `<ピーキング中>` は `peaking_flag.txt` の中身をそのまま(`true`/`false`、クォートなし)入れる。

## ショートカット2: 朝コンディション

```json
{
  "目覚め": { "number": <1-4> },
  "睡眠時間": { "select": { "name": "<5h未満|5-6h|6-7h|7-8h|8h以上>" } },
  "ピーキングフラグ": { "checkbox": <ピーキング中> }
}
```

## ショートカット3: 夜コンディション(通常時)

```json
{
  "体感": { "select": { "name": "<軽|並|重>" } },
  "気分指数": { "number": <1-5> },
  "不快指数": { "number": <1-5> },
  "開放": { "select": { "name": "<自慰|性行為|なし>" } },
  "好調・不調メモ": { "rich_text": [{ "text": { "content": "<メモ>" } }] },
  "ピーキングフラグ": { "checkbox": <ピーキング中> }
}
```

メモを入力しなかった場合は `好調・不調メモ` のキーごと省略する(空配列でもよい)。

## ショートカット3': 夜コンディション(ピーキング期の追加分)

`ピーキング中` が `true` のときだけ、上記に以下をマージする。

```json
{
  "炭水化物比率の体感": { "select": { "name": "<少なめ|適量|多め>" } },
  "塩分電解質メモ": { "rich_text": [{ "text": { "content": "<メモ>" } }] },
  "胃腸の負担感": { "select": { "name": "<なし|軽度|中度|重度>" } }
}
```

---

## 注意点

- **select は既存の選択肢名と完全一致させる**。表記ゆれ(`5-6h` を `5〜6h` 等)があると
  Notion側に新しい選択肢が勝手に増えて分析時にノイズになる。
- **rich_text の中身は必ずJSONエスケープする**。音声入力に `"` や改行が混ざると
  ボディが壊れて 400 が返る。ショートカットの「テキストをエスケープ」または
  「辞書」アクションでdictを組み立てて渡すと安全。
- 空文字を入れたくない項目は、キーごと省略すれば既存値が保持される。
- 400/401 が返ったときは、Integrationが「🏃 マラソン管理」ページにコネクト済みかを最初に疑う。
