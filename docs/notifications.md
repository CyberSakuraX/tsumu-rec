# 通知(コンディション系ナッジ)の設定

iPhone標準の「ショートカット」App →「オートメーション」タブ → 個人用オートメーションで設定する。
サーバーやClaudeを介さず、iPhone単体で完結する。

## 朝の通知(7:00)
1. 「+」→「時刻」を選択
2. 時刻: 7:00、繰り返し: 毎日
3. 「実行するショートカットを追加」→「朝コンディション」を選択
4. 「実行前に確認」を **ON** のままにする
   - ONにすることで、通知として表示され、タップすると初めてショートカットが実行される
   - (要件3.2「通知をタップ→選択肢をワンタップ」を満たすための設定)

## 夜の通知(21:30)
1. 「+」→「時刻」を選択
2. 時刻: 21:30、繰り返し: 毎日
3. 「実行するショートカットを追加」→「夜コンディション」を選択
4. 「実行前に確認」を **ON** のままにする

## 補足
- 通知をスワイプで消してしまった場合、その日の朝/夜の記録は行われない(欠測として許容する)
- 時刻を変更したくなった場合は、当該オートメーションを開いて時刻を編集するだけでよい
