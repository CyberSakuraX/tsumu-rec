# 食事記録 & マラソンピーキング活用システム 要件定義書 v1.0

作成日: 2026-07-23

## 1. 目的
- 日々の体調管理の土台をつくる
- レース前2〜3週間のピーキング期における栄養戦略の精度を上げる

## 2. 前提条件
- iPhoneを中心としたシンプルな入力
- 既存インフラ: Notion、Strava(MCP連携)、Claude
- マラソンシーズンは11月〜4月、オフシーズンは5月〜10月

## 3. 記録フロー

### 3.1 食事ログ(能動入力)
- 山崎さんが食後にひとこと話しかける(例:「昼、うまかっちゃん」)
- 発話はiPhone側の自動化(ショートカット等)を通じて、その場でNotion APIから新規DBへ直接書き込む
- Claudeは書き込み経路には関与しない

### 3.2 コンディション系(受動ナッジ)
- 朝の通知: 目覚め / 睡眠時間
- 夜の通知: 体感 / 気分指数 / 不快指数 / 開放 / 好調・不調メモ(任意)
- 通知をタップ → 選択肢をワンタップ → Notion APIへ直接書き込み

### 3.3 分析(依頼時のみ)
- 山崎さんが依頼したタイミングで、ClaudeがNotion MCP経由でデータを読み取り
- Stravaのトレーニングデータと突き合わせて、食事・体調とパフォーマンスの相関を分析する

## 4. データ項目

### 4.1 通常時
| 項目 | 内容 |
|---|---|
| 日付 | - |
| 朝食/昼食/夕食/間食 | 内容テキスト |
| 目覚め | 数値(1〜4等) |
| 睡眠時間 | 時間帯レンジ |
| 体感 | 軽/並/重 |
| 気分指数 | 数値 |
| 不快指数 | 数値 |
| 開放 | 自慰/性行為/なし |
| 好調・不調メモ | 自由記述 |
| ピーキングフラグ | true/false |

### 4.2 ピーキング期限定(レース前2〜3週間)
- 炭水化物比率の体感
- 塩分・電解質メモ
- 胃腸の負担感

## 5. 対象外にした項目
- 運動: Stravaから自動連携するため、手入力での二重管理は行わない
- 残業: 今回の目的(食事×体調×ピーキング)とは軸が異なるため除外

## 6. 非機能要件
- 入力は数秒で完結する軽さを最優先する
- iPhone単体で完結すること
- 既存のNotion/Strava環境とシームレスに統合すること

## 7. アーキテクチャ概要

```
[書き込み経路]
ユーザー(iPhone自動化) → Notion API → 新規DB

[分析経路]
Claude ⇄ Notion MCP ⇄ 新規DB
Claude ⇄ Strava MCP
```
