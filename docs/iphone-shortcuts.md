# iPhoneショートカット設計

## 共通の準備: 設定ファイル
Notion Token と database_id を1箇所にまとめ、全ショートカットから読み込む。
「ファイル」App → iCloud Drive → `Shortcuts` フォルダに `notion_config.json` を作成する。

```json
{
  "token": "secret_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "database_id": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
}
```

各ショートカットの先頭で「ファイルを取得」→「入力からディクショナリを取得」でこのJSONを読み込み、
`token` / `database_id` を以降のNotion APIリクエストに使い回す。

同じフォルダにピーキングフラグ用の `peaking_flag.txt`(中身は `true` か `false` の1行)を置く。

## 共通処理: 今日の行を upsert する
どのショートカットも、Notionへの書き込み直前に以下を行う。

1. 「日付を取得」→「日付をフォーマット」で `yyyy-MM-dd` 形式の文字列を作る(例: `2026-07-23`)
2. 「URLの内容を取得」で `POST https://api.notion.com/v1/databases/<database_id>/query` を実行し、
   `filter.property = "日付"`, `filter.date.equals = <今日の日付>` を投げる
3. 「辞書から値を取得」で `results` の件数を見る
   - 0件 → 「もし」アクションで分岐し、`POST /v1/pages` で新規作成(`parent.database_id` + `名前`/`日付` + 今回入力したプロパティ)
   - 1件以上 → 先頭の `id` を `page_id` として取り出し、`PATCH /v1/pages/<page_id>` で今回入力したプロパティのみ更新

ヘッダーは共通で以下を設定する。
```
Authorization: Bearer <token>
Notion-Version: 2022-06-28
Content-Type: application/json
```

## ショートカット1: 「ご飯記録」(食事ログ)
起動方法: ホーム画面アイコン / Siriフレーズ(例: 「ご飯記録」)/ Back Tap

1. 「メニューから選択」— 「何を記録する?」→ 朝食 / 昼食 / 夕食 / 間食(→変数`種別`)
2. 「テキストを書き取る」(Dictate Text)— 「内容は?」→ 発話をそのまま変数`内容`に格納
   - パース(自動解析)は行わない。発話全文をそのまま該当プロパティに保存するだけ。
3. 共通処理(今日の行のupsert)を実行し、`種別`に対応するプロパティ(朝食/昼食/夕食/間食のいずれか)に`内容`をセット
4. 通知は出さず終了(体感速度優先)

## ショートカット2: 「朝コンディション」
起動方法: 7:00の時刻オートメーション(下記 `notifications.md` 参照)から起動

1. 「ファイルを取得」で `peaking_flag.txt` を読み、変数`ピーキング中`に格納
2. 「メニューから選択」— 「目覚めは?」→ 1 / 2 / 3 / 4
3. 「メニューから選択」— 「睡眠時間は?」→ 5h未満 / 5-6h / 6-7h / 7-8h / 8h以上
4. 共通処理(upsert)を実行し、`目覚め`・`睡眠時間`・`ピーキングフラグ`(`ピーキング中`の値)をセット

---

## ショートカット3: 「夜コンディション」
起動方法: 21:30の時刻オートメーションから起動

1. 「ファイルを取得」で `peaking_flag.txt` を読み、変数`ピーキング中`に格納
2. 「メニューから選択」— 「体感は?」→ 軽 / 並 / 重
3. 「メニューから選択」— 「気分指数は?」→ 1〜5
4. 「メニューから選択」— 「不快指数は?」→ 1〜5
5. 「メニューから選択」— 「開放は?」→ 自慰 / 性行為 / なし
6. 「メニューから選択」— 「メモを残す?」→ はい(「テキストを入力」で自由記述)/ いいえ(空文字のまま)
7. もし `ピーキング中` が `true` なら追加で:
   a. 「メニューから選択」— 「炭水化物比率の体感は?」→ 少なめ / 適量 / 多め
   b. 「テキストを入力」— 「塩分・電解質メモ」(スキップ可、空でもよい)
   c. 「メニューから選択」— 「胃腸の負担感は?」→ なし / 軽度 / 中度 / 重度
8. 共通処理(upsert)を実行し、該当プロパティ一式をセット

## ショートカット4: 「ピーキング切替」
起動方法: ホーム画面アイコン(レース前2〜3週間の開始日・終了日にだけ手動で開く)

1. 「ファイルを取得」で `peaking_flag.txt` を読み、現在値を「通知」または「アラートを表示」で見せる
2. 「メニューから選択」— 「ピーキング期に切り替える?」→ ON / OFF
3. 「テキスト」アクションで `true` / `false` を作り、「ファイルを保存」で `peaking_flag.txt` を上書き

これ以降、朝・夜・食事ログの各ショートカットは自動的に新しいフラグ値を読み込むので、
日々の入力に追加のタップは発生しない。
